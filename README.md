<h1 align="center">呆猫伙伴 · Palico Companion</h1>
<p align="center">一个以《怪物猎人》艾露猫为灵感的 tModLoader 伙伴模组。</p>

## 一起冒险

- **战斗与支援**：给呆猫一把武器，它就会跟你一起战斗。搭配模组新增的支援装备，还能帮你回血、抵挡伤害、解除异常状态，投掷壶爆弹或扛起特大桶爆弹冲向怪群。你受伤时，它也会把附近的红心送过来。
- **采集与探索**：挖矿、砍树补种、照料药草、钓鱼、抓小动物、捡东西，它都能搭把手。还会在暗处帮你照明，发现附近的宝箱、生命水晶也会提醒你。
- **你的呆猫**：给它起名字、换衣服颜色、搭配染料。它会跟你搭话，头顶也会冒出表情。闲下来可以摸摸它、喂点吃的，还能把它当风筝放。

## 装备与背包

给呆猫搭配装备，也能保存多套配装，随时切换。

未使用的主武器会背在身后或挂在腰间，随动作移动；可在外观设置中关闭。

呆猫有自己的背包，能携带补给和战利品。收藏的物品可以照常使用，一键取回时会留在呆猫背包里。你还可以允许它使用指定箱子，帮你存放同类物品、补充消耗品。

![装备与背包](docs/images/04-equipment-zh-compact.png)

## 安装与上手

在 [Steam 创意工坊](https://steamcommunity.com/sharedfiles/filedetails/?id=3824240391)订阅并启用，进入世界即可遇到呆猫。适用于 **tModLoader 1.4.4**，支持简体中文、英文、单人和多人；已有角色与世界也能直接使用。

默认 `P` 打开面板、`K` 召回，按住 `V` 并左键指定工作目标。按键可在游戏控件设置中修改。

收回／叫出呆猫可单独绑定快捷键；面板支持手柄操作。连续点击面板里的剑形按钮，可依次切换主动进攻、协同进攻和不攻击。不攻击时仍可工作、拾取和治疗。

收集材料，为呆猫制作新装备，也能强化已有装备。装备怎么做、怎么用、还能怎样升级，都能在游戏内的「呆猫指南」里查到。

![呆猫指南](docs/images/05-guide-zh-compact.png)

## 按你的喜好调整呆猫能力

在「呆猫能力」设置中，可以选择三档强度预设：想自己当主力，可以选**辅助**；想和呆猫并肩作战，可以选**标准**；想轻松些、让呆猫带飞，可以选**强力**。默认使用标准档。

也能单独调整呆猫的伤害、生命、防御、回血继承比例、索敌范围、战斗移速、跟随与工作移速、闪避能力、工作速度和钓鱼速度。索敌范围可在 50%～150% 之间调整，默认 100%；不改变武器本身的射程，也不受强度预设影响。

回血默认继承主人通用附加回血的 50%，可调为 0～100%；设为 0 时只保留呆猫自身回血。受伤后的恢复计时独立计算，切换强度预设不改变继承比例。

还可以开启 Boss 生命增强，为并肩作战增加一些挑战；默认关闭。

联机时，能力设置由房主或服务器管理员统一配置，对服务器内的所有呆猫生效。

## 可选联动

这些模组都不是必需的：

- [魔法存储](https://steamcommunity.com/sharedfiles/filedetails/?id=2563309347)：允许呆猫使用后，它会帮你存东西、补充消耗品。
- [更好的体验](https://steamcommunity.com/sharedfiles/filedetails/?id=2797518634)：无限弹药等免消耗设置对呆猫也有效。
- [灾厄](https://steamcommunity.com/sharedfiles/filedetails/?id=2824688072)：呆猫在对应环境中、遇到 Boss 时有专门的台词，也支持部分武器的特殊用法。
- [瑟银](https://steamcommunity.com/sharedfiles/filedetails/?id=2909886416)：支持乐器、治疗工具和投掷武器的职业机制，包括独立灵感、友军治疗与投掷疲劳；还有 Boss、探索和支援时的情景台词。特殊操作的限制见下方兼容说明。

武器兼容与已知限制见[兼容说明](docs/COMPATIBILITY.md)。

暗影奥秘（SOTS）的刀光与虚空武器也做了适配，呆猫使用独立的虚空值。
